# 📖 Journal

> **Remember every day.** A clean, personal journaling web app to log daily thoughts, revisit past memories, and generate AI-powered monthly summaries.
I used AI for the Memories feature. Everything else was made by me only.
---

## ✨ Features

- ✍️ **Daily Entries** — Log and manage entries with a clean, distraction-free interface.
- 📅 **Calendar Navigation** — Quickly browse and jump between entries by date.
- ⏳ **Memories** — Relive moments with an "On this day" flashback view.
- 🤖 **AI Summaries** — Generate concise monthly reviews and reflections.
- 🔗 **Shareable Entries** — Securely share select entries via private share links.
- 🔒 **Authentication & Sync** — Secure user accounts and cloud storage powered by Supabase.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, FullCalendar, MDB UI Kit
- **Backend:** Node.js, Express
- **Database & Auth:** Supabase
- **AI:** OpenAI / Gemini API

---

## 🚀 Getting Started

### 1. Clone & Install

```bash
git clone https://github.com/your-username/journal.git
cd journal
npm install
```

### 2. Environment Variables

Create a `.env` file based on `.env.example`:

```env
REACT_APP_SUPABASE_URL=your_supabase_url
REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
PORT=3000
```

### 3. Build & Run

```bash
npm run build
npm start
```
